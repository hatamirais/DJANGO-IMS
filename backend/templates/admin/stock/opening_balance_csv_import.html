Format CSV

Setiap baris = 1 batch saldo awal. Baris dengan document_number yang sama akan dikelompokkan dalam 1 dokumen import saldo awal.

Kolom Wajib Keterangan
document_number Ya Nomor dokumen saldo awal, misalnya SALDO-AWAL-2026-001
effective_date Ya Tanggal efektif saldo awal. Format: DD/MM/YYYY atau YYYY-MM-DD
sumber_dana_code Ya Kode sumber dana
location_code Ya Kode lokasi gudang
item_code Ya Kode barang (kode_barang)
quantity Ya Jumlah saldo awal; harus lebih dari 0
batch_lot Tidak Opsional; otomatis dibuat jika kosong
expiry_date Kondisional Wajib untuk item yang memerlukan tanggal kedaluwarsa
unit_price Tidak Harga satuan; default 0

Kolom receiving_type dan supplier_code tidak digunakan pada import ini dan akan ditolak bila berisi nilai.
