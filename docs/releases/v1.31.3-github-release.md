# v1.31.3

Rilis patch ini menyederhanakan dashboard Instalasi Farmasi, memperbaiki akses dashboard auditor agar selaras dengan model izin laporan, dan menutup temuan dependency audit pada `tablib`.

## Changed

- Dashboard non-Puskesmas sekarang fokus pada area operasional utama.
- Kartu KPI atas, kartu KPI sekunder, dan ringkasan pergerakan stok 30 hari dihapus dari dashboard non-Puskesmas.
- Layout operasional mempertahankan `Transaksi Terakhir` di sisi kiri, dengan `Aksi Cepat` di kanan atas dan `Mendekati Kedaluwarsa` di bawahnya.
- Dashboard auditor sekarang menampilkan landing laporan yang berisi tautan laporan utama, bukan kartu atau section drill-through operasional.

## Fixed

- Akses dashboard auditor sekarang mengikuti izin laporan secara konsisten melalui Django permission `reports.view_reports` atau fallback REPORTS module-scope `VIEW`.
- Permission `reports.view_reports` sekarang diprovision melalui model marker unmanaged `reports.ReportPermission`, sehingga permission tersebut tersedia untuk assignment di database deployment.
- Test dashboard auditor sekarang memakai permission produksi yang diprovision, bukan membuat permission khusus hanya di test.

## Security

- `tablib` diperbarui dari `3.9.0` ke `3.10.0` untuk memperbaiki CVE-2026-9318 pada fungsi HTML export.

## Platform Notes

- Release ini memerlukan migration baru pada app `reports` untuk memprovision content type dan permission `reports.view_reports`.
- Migration tersebut menggunakan model unmanaged dan tidak membuat tabel laporan baru.
- Jalankan dependency install ulang setelah deploy agar pin `tablib==3.10.0` aktif.

## Verification

- `python backend\manage.py check`
- `.\scripts\run-django-test.ps1 -Target apps.core.tests -KeepDb`
- `.\scripts\run-django-test.ps1 -Target apps.reports.tests -KeepDb`
- `python -m pip_audit -r requirements.txt`
- `python -m pip_audit -r backend\requirements.txt`
